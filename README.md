# ✨ DocFlow AI — Organizador Inteligente de Textos e Tarefas

Aplicação web desenvolvida para demonstrar a aplicação prática de **Engenharia de Prompts** e **Inteligência Artificial Generativa (LLMs)** na automação de fluxos de comunicação, síntese executiva e organização de processos de negócio.

🔗 **Acesse a aplicação funcionando:** [https://wanderleiasames.github.io/docflow-ai/](https://wanderleiasames.github.io/docflow-ai/)

---

## 🎯 Problema Resolvido
Profissionais de operações, atendimento, educação e negócios lidam diariamente com grandes volumes de e-mails desestruturados, atas de reunião e demandas urgentes. O **DocFlow AI** transforma textos brutos em entregas acionáveis em segundos, reduzindo retrabalho operacional e padronizando a comunicação profissional.

## ⚙️ Funcionalidades
* **Modo Demonstração Instantânea:** Cenários reais de atendimento comercial, alinhamento de equipe e planejamento pedagógico prontos para testar com um clique.
* **Tripla Saída Estruturada:** Gera simultaneamente **Resumo Executivo**, **Lista de Tarefas Priorizadas** e **Resposta Profissional Pronta**.
* **Transparência de Engenharia de Prompts:** Exibe a estrutura de instruções (*System Prompt + Output Guardrails*) aplicada ao modelo.
* **Integração Real com Google Gemini API (Opcional):** Permite inserir uma chave gratuita do Google AI Studio para processar qualquer texto novo em tempo real.

## 🛠️ Tecnologias Utilizadas
* **Frontend:** HTML5, CSS3 (Interface Responsiva), JavaScript (ES6+)
* **IA & Prompts:** Engenharia de Prompts Estruturada, integração REST com Gemini API
* **Hospedagem:** GitHub Pages
